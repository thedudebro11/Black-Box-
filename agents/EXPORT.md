## Deliverables

### Report Generator

**`src/export/report-generator.ts`**

```typescript
export function generateReport(
  session: Session,
  result: AnalysisResult
): SessionReport
```

Produces a complete markdown string following exactly the template in
`docs/PHASES.md` Phase 8 section. The template:

```markdown
# Black Box Session Report
Date: [session.started_at formatted as readable date]
Issue Type: [session.issue_type formatted as readable label]
App / Game: [session.app_name]
Session ID: [last 8 characters of session.id only]

## Diagnosis
Confidence: [result.primary_confidence or 'INCONCLUSIVE']
Most Likely Cause: [result.primary_cause_name or 'Could not be determined']

[result.primary_output_text or inconclusive message]

## Evidence Found
[For each SignalMatch in result.all_signals_found:]
- [signal.technical] — [signal.description] ([seconds_before_marker formatted])

## Fix Recommendations
[For each FixStep in result.fix_recommendations, numbered:]
1. **[step.title]**
   [step.detail]

## Other Possible Causes
[If result.secondary_results is non-empty:]
[For each secondary RuleResult:]
- [secondary.rulePackId]: [secondary.confidence] confidence
  [secondary.outputText]

[If result.secondary_results is empty:]
No other causes were identified with significant confidence.

## All Signals Detected
[Complete list of all signals, technical format, for forum posting:]
[For each SignalMatch in result.all_signals_found:]
- [signal.technical] ([signal.window] window, [signal.severity])

---
Generated by Black Box v1.0.0
This report contains no personally identifiable information.
```

**Formatting helpers:**
- Issue type labels: `'crash' → 'Crash'`, `'bsod' → 'Blue Screen (BSOD)'`, etc.
- Date format: `'January 15, 2024 at 2:23 PM'` (locale-friendly)
- `seconds_before_marker` formatting:
  - `> 0`: `"[N] seconds before issue"` 
  - `=== 0`: `"at issue moment"`
  - `< 0`: `"[N] seconds after issue"`

**Session ID display:**
Only show the last 8 characters. Never the full UUID.
```typescript
const shortId = session.id.slice(-8)
```

**Privacy check built into the generator:**
- Never include `session.description` (user free text — may contain PII)
- Never include process arguments or file paths
- Never include full session ID
- Never include usernames or account names

### IPC Handler for Export

**`electron/ipc/export.ts`** (new file)

```typescript
export function registerExportHandlers(): void
```

Handle `export:save-report` channel:
- Receives: `{ markdown: string, filename: string }`
- Opens Electron save dialog: `dialog.showSaveDialog({ ... })`
- Default path: user's Documents folder
- File filter: `{ name: 'Markdown', extensions: ['md'] }`
- Writes file to chosen path using `fs.writeFile`
- Returns: `{ success: boolean, filePath: string | null }`

Register in `electron/main.ts`:
```typescript
import { registerExportHandlers } from './ipc/export'
// in app.whenReady(): registerExportHandlers()
```

### Preload Extension

Add to `electron/preload.ts`:
```typescript
export: {
  saveReport: (payload: { markdown: string; filename: string }) =>
    ipcRenderer.invoke('export:save-report', payload),
}
```

### UI Wiring

**Update `src/screens/Results.tsx`:**

Wire the "Export Report" button:
```typescript
const handleExport = async () => {
  if (!currentResult || !currentSession) return
  const report = generateReport(currentSession, currentResult)
  await window.electron.export.saveReport({
    markdown: report.markdown,
    filename: report.filename,
  })
}
```

Import `generateReport` from `src/export/report-generator`.
